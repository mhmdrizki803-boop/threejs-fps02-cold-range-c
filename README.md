A round-based tactical FPS in three.js. Mouse look, accelerated WASD with crouch, a rifle with
recoil and spread that punishes firing on the move, six bots that patrol, spot and shoot back,
90-second rounds that end in a win or a loss, and a HUD with health, ammunition, the round
timer and the target count. All geometry and materials are built in code: no textures, no
models, no audio files, no network, no build step.

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
